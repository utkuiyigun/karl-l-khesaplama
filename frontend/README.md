# Melon-Kar Frontend

Next.js 14 + TypeScript + shadcn/ui + Tailwind.

> **Durum:** Boş. Backend stabil olana kadar başlanmayacak.

## Plan

İlk dashboard sayfaları:
- `/login` — Magic link auth
- `/dashboard` — Genel kârlılık overview
- `/orders` — Sipariş listesi, filtrelenebilir tablo
- `/products` — Ürün kârlılık tablosu, COGS yükleme
- `/connections` — Trendyol API key bağlantısı
- `/simulations` — Kampanya simülasyonu

## Kurulum (zamanı geldiğinde)

```bash
npx create-next-app@latest . --typescript --tailwind --app
npx shadcn-ui@latest init
```
